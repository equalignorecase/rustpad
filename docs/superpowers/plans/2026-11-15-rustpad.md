# RustPad Implementation Plan

> Native execution in this session, as requested by rustpad.txt. No additional approval gate.

**Goal:** Build a safe, offline macOS text editor, not a mockup.
**Architecture:** Rust owns authorized file handles, dialogs, safe writes, external-change checks and local configuration. CodeMirror owns text, history and selection; Zustand owns tab metadata and settings. React provides the compact graphite shell.
**Tech Stack:** Tauri 2, Rust, React, TypeScript strict, Vite, Tailwind 4, CodeMirror 6, Zustand, Radix/shadcn components, Lucide, pnpm.
**Spec:** ../../../../rustpad.txt

## Global Constraints
- No network, telemetry, shell execution, accounts or database at runtime.
- Never overwrite external changes, decode lossy UTF-8, or lose unsaved text on close.
- Preserve untouched bytes, BOM and mixed line endings. Limit files to 10 MiB.
- Native dialogs authorize paths; IPC uses opaque document IDs.

## Review Focus
- Failed or cancelled Save As must not close or mark a document clean.
- Undo to saved text clears dirty state; editing during save remains dirty.
- External edits and deletion must block saves; reload needs explicit consent.
- UTF-8 BOM, Thai, emoji, mixed line endings and readonly mode need real filesystem tests.
- Close/quit must serialize prompts and wait for writes; cancelled close keeps all tabs.
