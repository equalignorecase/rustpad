
You are a senior Rust engineer, Tauri 2 engineer, React/TypeScript developer, desktop application architect, and macOS UI/UX designer.

PROJECT: RustPad — A modern, lightweight, offline-first text and source code editor for macOS, inspired by the practical workflows of Notepad++ and the polished visual feel of modern macOS code editors.

GOAL
Build a genuinely functional desktop app, not a UI prototype. Target macOS Apple Silicon and Intel. Use Tauri 2 with Rust for native backend functionality and React, TypeScript, Vite, Tailwind CSS v4, CodeMirror 6, Zustand, shadcn/ui, Radix UI, and Lucide React for the frontend. Use pnpm. No web server, user accounts, cloud sync, database, analytics, or telemetry.

ARCHITECTURE
Frontend:
- React + TypeScript strict mode with Vite.
- CodeMirror 6 manages active editor document, selection, history, extensions, and language support.
- Zustand stores document metadata, ordered tab IDs, active tab, UI preferences and operation status; do not mirror the complete CodeMirror document into Zustand on each keystroke.
- React components: AppShell, Titlebar, TabBar, Sidebar, EditorPane, FindReplacePanel, CommandPalette, StatusBar, SettingsDialog, UnsavedChangesDialog, ToastSystem.
- Use typed, centralized Tauri command wrappers.

Backend:
- Rust Tauri commands for read_document, save_document, inspect_document, and persistence helpers.
- Use std::fs or appropriate asynchronous file I/O.
- Serde for serialization, error types and validated IPC responses.
- Strong separation between file operations, document metadata, path authorization, settings and Tauri integration.
- All filesystem requests must be verified; avoid arbitrary untrusted path access.
- Never execute text file contents.

CORE FILE FEATURES
- New document (Cmd+N), Open (Cmd+O), Save (Cmd+S), Save As (Cmd+Shift+S), Close Tab (Cmd+W).
- Multiple open documents with closable/reorderable tabs and active tab selection.
- Dirty indicators based on document revisions or saved snapshots, not simply whether a key was pressed.
- Prompt Save / Don't Save / Cancel for modified documents before closing a tab or window.
- Handle Cmd+Q and native window close, respecting asynchronous save decisions without closing prematurely.
- Open selected files with native macOS dialogs.
- Drag and drop files onto the window.
- Support open-with/Finder integration where feasible and test it in packaged builds.
- Recently opened files, with missing-file handling.
- Restore tabs and selected editor position where possible, but never silently overwrite unsaved data.
- Detect binary and unsupported content; show a non-destructive message.
- Detect invalid UTF-8 and offer safe options rather than lossy automatic replacement.
- Support UTF-8 with and without BOM, preserve original line endings where possible, and let users explicitly convert LF/CRLF.
- For unsupported legacy encodings, show a clear limitation or implement verified decoding with an explicit selection.
- Avoid unintended newline or encoding changes when saving an untouched file.
- Use safe same-directory temporary-file writes when feasible, sync and replace carefully; preserve permissions where practical.
- Report disk, permission, read-only, deleted-file and external-modification errors.
- Detect external file changes and prompt Reload / Compare if available / Keep Local Changes, without overwriting blindly.

EDITOR
Use CodeMirror 6 with appropriate maintained extensions:
- Line numbers, active line highlighting, indentation guides when available.
- Syntax highlighting for Rust, TypeScript, JavaScript, JSON, HTML, CSS, Markdown, Python, PHP, SQL, TOML and plain text.
- Automatic language recognition from file extension and manual language mode selection.
- Undo/redo, selection, copy/paste, bracket matching, auto-close brackets, automatic indentation, code folding.
- Tab/space indentation with configurable size.
- Line wrapping toggle, font size and font family preferences.
- Find, Find Next/Previous, Replace, Replace All, case sensitivity, whole-word and regex modes.
- Go to line/column, basic command palette.
- Cursor position, selection length, line count, indentation, line-ending format, encoding and language in status bar.
- Ensure Unicode-safe text handling, Thai input, macOS IME composition, emoji, and combined characters.
- Do not implement a custom document parser or text editor engine unless CodeMirror truly cannot meet a requirement.
- Handle large files without freezing the UI where practical; enforce and explain thresholds instead of claiming unlimited performance.

USER EXPERIENCE / DESIGN SYSTEM
Create a premium, restrained modern macOS interface: minimalist, practical, quiet, responsive and developer-focused.
- No marketing landing page, dashboard cards or oversized headings.
- Use dark theme as default with carefully designed light theme.
- Palette: deep graphite surfaces, low-contrast borders, muted accent color, clear typography and subtle selection states.
- Compact draggable macOS-friendly titlebar with native traffic light controls preserved.
- Horizontal tabs, optional collapsible sidebar, large editing canvas, compact bottom status bar.
- Sidebar contains Open Files and, when a folder is opened, an expandable file tree.
- Smooth, subtle transitions without expensive continuous effects.
- Good keyboard accessibility, focus indicators, ARIA labels, appropriate contrast and support for macOS system font sizing.
- Use CSS variables for theme tokens and consistent component states.
- No fake buttons, fake loading states or decorative controls without behavior.
- Respect macOS conventions and avoid covering the native window controls.
- Support small window sizes and normal Retina displays.

SETTINGS
Provide persisted settings for:
- Theme: System / Dark / Light
- Editor font family and font size
- Tab width and tabs versus spaces
- Word wrap
- Show line numbers
- Auto indent and bracket matching
- Recent files visibility and restore session
- Auto save: Off by default; optional delayed save with clear behavior and safe write rules
- Preferred line ending for newly created files

Store configuration locally in the OS-appropriate application configuration directory using safe writes and schema defaults. Do not store secrets, entire document contents or absolute paths in logs.

SECURITY / PRIVACY
- Fully offline use. No backend server or network dependency at runtime.
- No external CDN, telemetry, analytics, account, or auto-update in the first release.
- Never enable unrestricted shell execution or remote content loading.
- Use minimal Tauri capabilities and plugin permissions.
- Use native dialogs and deliberate document authorization rather than exposing unrestricted filesystem operations to arbitrary frontend inputs.
- Treat file contents as untrusted text. Never inject them into HTML, execute scripts or render raw unsafe HTML.
- Validate payload sizes, file paths and errors at Rust IPC boundaries.
- Follow macOS privacy and sandbox behavior applicable to the selected distribution mode.
- Avoid exposing sensitive paths, filenames and document contents in error logs.
- Add a restrictive Content Security Policy compatible with the bundled application, and document any development-only exceptions.
- No silent data deletion; a failed save must leave original data recoverable.
